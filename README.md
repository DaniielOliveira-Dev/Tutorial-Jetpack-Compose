# Tutorial Jetpack Compose

Este repositório contém a implementação do tutorial introdutório de **Jetpack Compose**, desenvolvido como atividade acadêmica.

## 📱 Sobre o projeto

O projeto foi criado utilizando o template **Empty Activity** do Android Studio e desenvolvido seguindo o tutorial oficial de introdução ao Jetpack Compose.

Durante o tutorial, foram praticados conceitos fundamentais para a criação de interfaces Android utilizando o framework declarativo Jetpack Compose.

## 🚀 Conteúdos praticados

Durante o desenvolvimento do projeto foram abordados conceitos como:

- Criação de interfaces com Jetpack Compose;
- Funções `@Composable`;
- Uso de `Text`;
- Organização de layouts com `Row` e `Column`;
- Utilização de `Modifier`;
- Aplicação de espaçamentos e dimensões;
- Uso de imagens;
- Criação de componentes reutilizáveis;
- Material Design;
- Gerenciamento de estado;
- Interação com componentes;
- Criação de listas utilizando `LazyColumn`;
- Utilização de `items`;
- Criação de previews com `@Preview`;
- Visualização da interface nos modos claro e escuro.

## 🛠️ Tecnologias utilizadas

- Kotlin
- Android Studio
- Jetpack Compose
- Material Design
